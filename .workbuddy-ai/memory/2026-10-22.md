## Session 3 — serving-path defect fixed (biggest win of the night)

Root cause of the 92.9%->77.7% drop through `choose()`: **459 of 800 val rows in one
contiguous block were `hdv.list {item, price_rule:"fixed"}` with no price** — goals
like "put X on the market" state no price, the model still emits `fixed`, and the
cross-parameter rule (`fixed needs an integer price`) rejected the whole call,
discarding a correct tool choice and a correct item span over one optional field.

Fix: `ai/postprocess.py` step 8 drops `price_rule` when it is `fixed` and `price` is
not an int. Dropping is not guessing a price — the schema default applies, which is
what the gold label does. A goal that states a price keeps the rule.

Measured (INT8, full splits, serving path with postprocess + resolvers):

| split | before | after |
|---|---|---|
| val call | 0.663 | **0.812** |
| val tool | 0.777 | 0.928 |
| gold call | 0.718 | 0.718 |
| val_indist call | 0.893 | 0.897 |

Invalid calls across 2,273 sampled val rows: 481 -> 14. INT8 vs fp32 delta on call:
**+0.000** everywhere; latency 60 ms vs 151 ms.
